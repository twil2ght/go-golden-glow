## Tips for teaching
### Natural language when Natural language
- normally,you can teach by using "if-then" template

### Machine language when meeting implicit operations
- when encountering some words with hidden operations;
- E.g.`if...then you can talk about the weather`;
- before talking about the weather,you must know the weather of which place;
- but this implicit operation won't be taught by natural language;
- so teach it via machine language:`[input]` and `[output]`
